## 🌟 Task 1: Personal Developer Portfolio (`portfolio-website/`)

An award-winning personal engineering portfolio built for an AI/ML and Full-Stack engineer.

### Key Highlights
- **Spring-Loaded 120 FPS Scrolling**: Powered by the Lenis smooth scroll engine with damped harmonic spring oscillator easing ($x(t) = 1 - e^{-5.5t}\cos(3.8t)$).
- **Interactive 3D Card Tilt & Radiant Halo Aura**: Refined Apple/Linear-grade 3D card tilt (±4.5° pitch/yaw) paired with multi-layered celestial atmospheric halo corona effects (`box-shadow` spreads with zero text wash-out).
- **High-Contrast Dark / Light Theme Engine**: Deep obsidian cyber dark mode by default (`#0a0d14` canvas, `#111726` surface) with instant toggle to clean light mode and `localStorage` persistence.
- **Strict Boundary Containment**: All cards use `overflow: hidden` to prevent clipping or viewport overflows.
- **ATS-Friendly Resume System**: Embedded interactive resume viewer and print-to-PDF utility (`assets/resume.html`).
- **Interactive Project Filtering**: Instant categorization (`All`, `AI & Hardware`, `Full Stack & Web Apps`, `Automation & IoT`).

## 🛠️ Getting Started & Local Execution

No heavy frameworks, bundlers, or package installations are required. All tasks run natively in modern web browsers:

```bash
# Clone the repository
git clone https://github.com/vaibhavsb444/week1-assignments.git

# Navigate into the project folder
cd week1-assignments

# Open any task directly in your browser:
# Task 1:
start portfolio-website/index.html

# Task 2:
start business-landing-page/index.html

# Task 3:
start css-challenge/index.html
```

Or serve via any static HTTP server (e.g. VS Code Live Server, Python `python -m http.server 3000`, or Node `npx serve`).
