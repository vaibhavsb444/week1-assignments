Frequently Asked Questions

What are your core technical strengths?

My strengths bridge both Artificial Intelligence & Machine Learning (Python, PyTorch, OpenCV, offline LLMs via Ollama/Qwen, Raspberry Pi) and modern Full Stack Engineering (React, Vite, HTML5, CSS3, JavaScript, Firebase, MongoDB, PHP, and cloud Vercel edge deployment).

What is the architecture behind Clodhi.com?

Clodhi.com is a streetwear e-commerce startup that I founded and engineered end-to-end. I built the complete frontend using React and Vite, integrated Firebase authentication and database management, configured custom domain routing, and deployed the platform onto Vercel's global CDN.

How does AIVA operate completely offline?

AIVA runs local quantized Large Language Models (like Qwen via Ollama) directly on a Raspberry Pi 4 board. Using on-device speech-to-text and NLP intent classification, it provides campus navigation and information with zero cloud latency and complete data privacy.
